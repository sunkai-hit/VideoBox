# VideoBox · AI视频智能分析系统交互原型

基于客户《AI视频盒子整体规划》三部分系统范围，参照 `sunkai-hit/BaseFream`（JeecgBoot Vue3 / Ant Design Vue）企业后台视觉规范制作的独立高保真可交互原型。

## 快速预览

**最简单方式：直接用 Chrome / Edge 浏览器打开 `index.html`。** 无需安装依赖、连接后台或启动数据库。

可选本地服务运行：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```

## 覆盖范围

| 子系统 | 页面 |
| --- | --- |
| AI模型生产平台 | 工作台、数据集管理、在线标注、模型训练、转换与量化、仿真测试、制品版本管理、自然语言建模助手 |
| 中心管理平台 | 总览、制品仓库、边缘设备管理、通道与算法配置、下发任务、告警数据、用户与权限 |
| 边缘算法盒子 | 运行总览、视频接入、推理跟踪、离线缓存与补报、本地运维与日志 |

## 完整交互演示

1. **模型生产闭环**：模型生产平台 → 数据集 → 标注 → 训练 → PT/ONNX/RKNN 转换 → 仿真 → 发布。
2. **远程部署闭环**：模型生产端发布制品 → 中心仓库自动显示 → 选择在线边缘设备下发 → 边缘端已加载制品更新。
3. **告警管理闭环**：边缘端模拟告警 → 中心告警列表 → 查看详情/抓拍 → 标记已确认 → 导出CSV。
4. **断网恢复闭环**：边缘端模拟断网 → 本地仍产生告警 → 缓存队列可见 → 恢复联网 → 自动补报 → 中心可查看结果。
5. **智能体演示**：自然语言输入 → 自动生成配置建议 → 一键模拟生产全流程 → 生成待发布RKNN制品。

## 演示数据

- 所有数据保存在当前浏览器的 `localStorage` 中，可跨三个子系统联动。
- 点击顶部「重置数据」恢复初始化状态。
- 所有AI训练、视觉识别、模型转换、设备重启、网络断连和告警均为**演示模拟**，不会与实际硬件或云平台交互。
- 标注画布为目标框示意，不提供真正图形标注器或数据集存储。
- 模型制品 / 版本 / 精度 / 负载 / 视频画面 / 告警和账号均为模拟信息，不能作为性能或实现承诺。

## 技术与下一步

本目录是**独立零依赖交互演示版**，采用 HTML / CSS / JavaScript，以便客户直接双击打开文件验证流程；视觉与交互规范参考 BaseFream，而非完整复制其代码和依赖。正式前端实施时，可迁移至 `Vue3 + TypeScript + Ant Design Vue`，复用 BaseFream 的路由、布局与组件机制，并将模拟状态替换为 API。
