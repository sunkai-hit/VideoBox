# AI 视频智能分析管理平台 · V0.3 统一交互原型

本目录保存 **V0.3 可直接离线运行的完整交互原型**。

## 使用方式

下载 [index.html](./index.html)，使用 Chrome 或 Edge 浏览器打开即可；无需数据库、Node.js 或后端服务。视频画面资源已内嵌在 HTML 中。

## 主要调整

- 合并原先的“三平台切换入口”，采用一个统一 Web 管理界面。
- 统一导航包含综合工作台、监控大屏、模型生产、制品管理、设备与通道、告警管理、系统管理。
- 边缘算法盒子的运行状态及必要运维能力通过 **边缘设备管理 → 运行详情** 访问，不作为独立产品入口。
- 保留设备制品下发与**具体视频通道关联算法**两个相互独立的操作步骤。
- 保留断网缓存、联网补报及跨模块演示数据联动。

## 演示流程

1. 在模型生产模块创建数据集、完成标注、模拟训练、转换、仿真并发布制品。
2. 在制品仓库选择目标设备进行模拟下发。
3. 在通道与算法配置中选择设备和通道，配置算法和运行参数，保存并下发。
4. 从边缘设备列表进入运行详情，查看通道配置、模拟断网、产生告警并恢复连接。
5. 在中心告警管理、综合工作台或监控大屏查看补报结果。

> 注意：本版本是用于需求评审的**演示原型**，不具备真实模型训练、RKNN 推理、设备通信或真实告警处理能力。UI 参考用户的 BaseFream (JeecgBoot Vue3 / Ant Design Vue) 企业后台风格，实际代码采用离线 HTML/CSS/JS 实现，不是已迁移的 Vue3 正式工程。
